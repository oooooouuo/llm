# 模型接口契约

现存脚本依赖 `model_interface.UnifiedModelInterface`，本次材料不包含其实现。仓库不提供模拟响应或伪造模型调用。

使用者需在根目录自行补充 `model_interface.py`：

- 暴露 `UnifiedModelInterface(model_name=...)`，接受 `gpt-4o`、`llama-3.1-70b`、`deepseek-v3` 中实际运行的别名。
- 实例提供 `generate_response(prompt, max_tokens=1024)`，返回真实服务生成的字符串。
- 在接口内部将别名映射到有权限访问的真实模型 ID、供应商和端点；不能只根据别名假定版本。
- 从环境变量或系统凭证管理器读取密钥，不将密钥写入代码、日志、异常文本或版本控制。`--save-prompt` 和 `--save-response` 均默认关闭。
- 按供应商实际语义配置输出 token 上限、温度、超时、请求重试和速率限制；保留真实设置与不可变模型版本记录。主脚本不提供通用服务 SDK 或统一重试实现。
- 服务失败应抛出异常并终止运行，不把错误字符串伪装成模型答案；空响应按错误预测计入分母。

【该配置文件需要使用者自行根据数据集/模型凭证补充】：接口要求的本地凭证配置及模型别名到真实服务的映射。具体变量名称和配置格式取决于补充的接口，当前不编造 `.env` 模板、供应商端点或 API 参数。

补齐接口后，安装并记录其真实 SDK 依赖。默认 `.gitignore` 忽略整个本地 `model_interface.py`；若以后决定公开它，先完成脱敏审查，再显式调整忽略规则。静态检查只确认该文件存在，不验证类、方法和真实服务连通性。
