# 发布变更与方法边界

## 可运行工具链

本次发布提供凭证脱敏的 HTTP 模型适配器、输入清理和独立分组、公开 WSD 数据下载与 XML 转换、编码器准备及离线流程验证。运行不再依赖未发布的旧接口或旧配置文件。恢复的凭证不纳入代码，也不用于本次验证。

模型组与实际请求 ID 分别记录，校验服务返回的模型身份。API token 上限透传，错误不会被伪装成普通回答。每条成功响应即时写入本地 journal；当前仍不自动续跑。

## 评估协议

1. 候选词义由独立词典提供，不将目标正确标签加入检索候选。
2. 示例库和评估集分离。准备阶段按人工数据共享词义、真实文档与相同句子关联成组，再做确定性划分；这不是历史划分。
3. 同一句子的不同目标实例分别保留；同目标冲突标注隔离，一致重复去重，保留排除记录。
4. 最终 JSON 中完整词义标识符精确判分，不接受数字片段或分析正文命中。
5. 按模型、来源、语言和难度配对 Baseline；没有同组对照时不计算改进值。
6. 每次运行隔离输出与进度。缺失输入和接口异常明确终止；无选中样本时不导出空实验结果。

以上变化会影响示例覆盖和结果，不能将新结果直接替代论文历史数值。人工数据的词义隔离尤其可能使英语中没有目标词义示例。缺少英语池时只允许显式单语回退，并记录该策略。

## 数据与编码器

公开真实语料重新获取后按明确的新转换规则处理，保留来源与输入指纹。CSV 的难度标签与运行时策略分数分别记录。候选缓存只清除空项和非法格式，不用金标补建词典。

编码器保留 E5 语言代码前缀与 MiniLM 加权选择方法；对 E5 表示增加运行内缓存以避免重复编码。本地 E5 权重缺少模块元数据时，可在新的本地目录复用权重并取得官方 pooling 配置。架构检查不等同于权重身份验证。

## 验证边界

真实编码器的离线流程已进行本地验证，调用结构和数据隔离由单元测试覆盖。付费模型端到端实验、全部历史响应重评分与论文结论验证尚未完成。当前没有通过新运行提供论文性能数值。

复杂度是表层启发式，不能等同于语义难度。真实来源有独立的示例数和系数，英语使用单语回退；已有版本不能推断每个模块的独立因果贡献。静态隔离检查也不能排除所有改写、翻译对齐或预训练污染。
