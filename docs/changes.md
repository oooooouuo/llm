# 整理变更与方法边界

输入范围为现存 `experiment_runner1_v2.py`。论文历史稿只用于理解项目背景，没有据其文字生成指标文件、实验图表或测试日志。原始附件未改动，未收入公开文件夹。

## 公开整理

移除已排除对比模型的全部调用标识、专用提示、检索开关、采样、输出预算、重试分支及相关注释，保留通用处理路径。删除未经证据支持的性能保证与验证通过注释。没有加入对应的历史结果描述。

增加命令行选择、标准库输入检查、接口契约、数据字段说明与本地输出隔离。删除全局强制离线、禁用 TLS 验证、清空代理及导入时重复加载模型行为。配置中真实数据阈值继续保留原值与最小值约束，未调整成实验调参结果。

## 影响评估口径的修正

1. 原实现把目标样本的真实标签加入检索候选集合。公开版仅使用独立候选词典，不向检索路径传入目标真实标签；预检只验证词典覆盖，不修改候选集合。
2. 原实现从当前评估数据读取示例池。公开版要求独立示例目录，检测跨集合归一化完全相同句子。此项会改变可用示例，需要使用者建立可核查的数据划分。
3. 原实现允许答案正文、ID 子串及数字片段命中。公开版按最终 JSON 中完整标识符精确判分，不从分析文字中搜正确答案。
4. 原实现计算 Baseline 增益时未区分数据来源，报告还跨模型或来源平均。公开版将数据来源写入结果字段，按完整实验单元配对；缺少同组 Baseline 时留空。
5. 原进度文件可跨运行跳过任务，但加载结果依赖新的时间戳。公开版每次运行使用独立目录，不宣称支持中断续跑，避免历史进度导致缺项。
6. 原实现缺少难度列时可能重复评估整份数据。公开版强制评估集有合法难度列；模型接口初始化失败或数据读取异常直接报错，不静默遗漏模型组。

这些修正会影响结果与可比较性，需要重新进行真实实验。它们不是性能改进证据，也不是论文结论已被验证的证明。

## 仍需记录的限制

复杂度是表层启发式，不能等同于语义难度。真实数据有示例数上限和独立的语义系数，英语没有跨语言检索，因此各来源与语言的策略并非完全一致。汇总 `complexity_strategy` 对自适应组仅说明查看样本明细；逐样本策略以明细中的 `adaptive_k`、`use_cot` 为准。

没有原始依赖版本声明、数据构建流程、词义资源版本或模型接口实现，因而本仓库不能独立确定论文使用的完整执行环境。使用者必须记录补齐材料及新运行设置，不得声称补充配置就是原配置。

现有实验矩阵没有检索模块、采样模块各自的单独消融组；没有重复种子统计或显著性检验。语义近重复与跨语言平行样本泄漏、模型预训练污染，以及服务端模型更新都不能由静态检查排除。
