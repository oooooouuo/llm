# 发布变更与方法边界

本次发布保留多语言 WSD 的检索、示例选择与自适应提示流程，并调整数据隔离、判分和结果导出。以下变更会影响实验协议，应在比较不同版本时加以说明。

## 发布范围

实验入口为 `experiment_runner1_v2.py`。模型配置包含 gpt-4o、llama-3.1-70b 和 deepseek-v3，统一采用通用提示与调用流程。数据来源与输入格式见 [data_schema.md](data_schema.md)。

代码提供命令行分组选择、输入检查、配置记录和独立输出目录。模型下载与缓存遵循本地环境配置，不覆盖代理，不关闭 TLS 校验。

## 评估协议调整

1. **候选词义与检索**：移除目标正确标签参与检索的路径，仅使用独立候选词典约束检索。预检验证候选覆盖，不修改候选集合。
2. **示例库隔离**：将示例库与评估集分开读取，检查跨集合归一化后的完全相同句子，避免直接从评估集选择示例。
3. **精确判分**：使用响应结尾 JSON 中的完整词义标识符判分，不再接受正文命中、ID 子串或数字片段匹配。
4. **结果分组**：在结果中显式记录数据来源，按模型、来源、语言和难度配对 Baseline。缺少同组 Baseline 时不计算改进值。
5. **运行隔离**：每次调用使用独立目录，不复用其他运行的进度；当前不支持中断续跑。
6. **失败处理**：要求评估数据包含合法难度标签；接口初始化失败或数据读取异常时终止运行，避免静默遗漏实验组。

新协议下的运行结果应单独记录，不能直接替代论文报告。上述变更尚未通过真实模型的端到端实验验证。

## 方法边界

复杂度分数采用词数和标点数的表层启发式，不等同于语义难度。真实数据有示例数上限和独立语义权重，英语目标采用单语回退；各语言与来源的处理策略并非完全相同。

当前实验组包括 Baseline、关闭推理提示的自适应组及完整组，没有检索、语义采样和自适应示例数各自的独立消融。该矩阵不能用于估计所有模块的独立因果贡献。

完全重复检查不能排除平行语料、同源文档或语义近重复泄漏。数据划分需要结合语料来源进一步审查。远程模型更新与预训练污染也不在静态检查覆盖范围内。

## 复现记录

运行记录应包含代码提交、输入哈希、处理程序、候选资源版本、模型快照、SDK 和服务参数。当前发布不包含完整数据处理与生成程序、历史环境锁定文件或模型接口实现；本地补充的配置应与相应的新运行一同记录。
