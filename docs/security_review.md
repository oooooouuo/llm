# 凭证与数据管理

模型接口涉及服务凭证与外部数据传输，实验输出可能包含受许可约束的文本和词义标注。运行与发布时应遵循以下约定。

## 凭证

模型服务适配器应从环境变量或系统凭证管理器读取密钥，不将凭证写入源码、日志或异常文本。服务端点、认证头、代理配置与私有安装源应在本地管理。

`.gitignore` 默认忽略本地 `model_interface.py`、环境配置和常见凭证文件。公开适配器前，先移除密钥与私有端点，再调整忽略规则。不要为解决网络问题关闭 TLS 校验。

## 数据传输与输出

模型调用会向所选服务发送输入文本，运行前应确认数据许可及服务条款允许该传输。

提示与响应默认不保存，但样本级 CSV 仍包含输入句子、目标词、真实标签与候选释义。运行输出、临时结果、进度和日志默认保留在本地；修改 `--output-dir` 后应同步设置忽略规则。

第三方数据、候选词义资源及模型权重遵循其各自许可，本仓库 MIT 不授予这些材料的再分发权利。

## 发布检查

- 检查适配器、依赖记录和错误信息中是否含凭证、内部主机名或私有路径。
- 检查暂存文件，排除数据原文、缓存、运行输出和本地文稿。
- 检查 `pip freeze` 中的本地路径、私有索引及认证 URL，再决定是否公开环境锁定文件。
- `.gitignore` 不清除已有 Git 历史。密钥若曾进入公开历史，应先撤销并更换，再处理历史记录。
- 提交署名与邮箱会进入 Git 历史，可使用 GitHub 隐私邮箱。
