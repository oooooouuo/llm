# 凭证与数据管理

## 凭证与适配器

公开的 `model_interface.py` 从环境变量或本地 `.env` 读取凭证，不包含历史密钥或个人路径。`.env.example` 仅提供空凭证项与公开服务地址。接口不回显服务错误返回体，不将密钥写入运行元数据，也不将授权头跟随到重定向地址。

本地旧密钥不用于本次验证；若旧源码曾包含硬编码凭证，应在对应服务撤销或更换。不要通过真实请求测试未知状态的旧凭证。

## 数据、权重与输出

`local_data/`、`models/`、`.cache/`、`.venv/` 和 `outputs/` 被 Git 忽略。数据准备产生的排除记录、来源指纹及原始下载包都保存在本地，不应随整个目录上传。第三方资源按各自条款使用，MIT 只覆盖有权发布的原创代码与文档。

真实生成调用会发送输入文本。样本明细与 journal 包含原文、标注和候选释义；即使关闭提示与响应保存，也不等于输出不含敏感数据。修改输出目录后须同步设置忽略规则。

## 发布检查

- 检查实际暂存内容，而不只看 `.gitignore`；排除凭证、个人路径、数据原文、权重、缓存与运行输出。
- 对公开环境清单确认不含私有安装 URL、认证参数和本地路径。
- 不将聊天归档、论文历史稿、未核实的历史结果或旧错误配置收入仓库。
- `.gitignore` 不清除已存在的 Git 历史；凭证泄漏时须先撤销更换，再处理历史。
- Git 提交作者和邮箱会进入历史，可使用 GitHub 隐私邮箱。
