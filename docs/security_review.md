## 代码检查发现与处理

未在所提供的实验脚本中发现直接写入的 API 密钥、个人邮箱或个人绝对路径。代码依赖的模型接口实现未提供，因此无法确认其凭证、端点与异常信息是否安全。默认忽略本地 `model_interface.py`，补充后先审查，再决定是否公开脱敏版本。

原代码包含禁用 TLS 校验、强制离线及删除代理环境变量的全局设置，公开版已移除；模型下载和本地缓存由使用者管理。模型名是公开标识，不是凭证。

原代码默认保存响应。公开版默认不保存提示与响应，但样本级 CSV 仍含句子、目标词、真实标签与候选释义。所有运行输出、临时结果、日志和进度默认被 Git 忽略；如通过 `--output-dir` 改到其他目录，需同时添加相应忽略规则。

## 需要由使用者处理的项目

- 检查补充接口的密钥、认证头、端点、内部主机名、代理、私有 SDK 安装源和异常打印；凭证放环境变量或系统凭证管理器，避免打印完整请求。
- 确认有权把数据发送给外部模型服务，以及有权保存、分享句子、标签与词义释义。数据与缓存被忽略不等于取得数据授权。
- 确认模型权重、词义资源与数据的许可；MIT 只覆盖有权发布的原创代码与文档。
- 原脚本、论文历史稿和其他附件未收入整理目录。论文定稿、作者与单位信息、批注修订和元数据应单独审核；不要把上级目录或全部 Downloads 直接打包。
- 使用真实运行生成环境锁定时，检查本地路径、私有仓库 URL 与认证信息；不要直接公开未经审查的 `pip freeze`。
- `.gitignore` 不清除 Git 历史，也不是密钥扫描器；上传前人工检查 `git diff --cached`。若密钥曾公开，先撤销再替换，不能只删除当前文件。

本次整理未创建压缩包、未调用模型服务。发布内容应以仓库中的实际文件与提交记录为准。
