# 数据与资源约定

仓库不分发数据、模型权重或词义资源。下文区分论文已经说明的数据来源、上游当前提供的材料，以及仍需核实的项目处理步骤。

## 论文记载的数据来源

根据项目论文历史版本 IV-A（Data）及 Data Availability 段落：

- `real`：带有 BabelNet 或 WordNet 关联词义标签的多语言真实上下文，论文明确指向 [SapienzaNLP/mwsd-datasets](https://github.com/SapienzaNLP/mwsd-datasets) 作为公开上游资源。
- `artificial`：围绕显式词义标识符生成的句子，并具有三个标注难度层级。
- `problem`：以丰富干扰项或领域上下文增加歧义的项目构造数据。

这三类来源及其性质已有论文依据。论文没有给出后两类数据的独立下载地址，也未完整记载其生成提示、生成模型、采样参数和审核程序；这些内容仍需补充真实材料。本文不复写历史性能、样本统计表或评估结果。

## 获取公开上游材料

截至 2026-10-21 核对，上游 README 提供 SemEval-2013 与 SemEval-2015 的多语言数据下载入口，并区分 `all` 与 `wn` 两个子集；英语资源另行指向 Raganato 等人的 [English WSD Evaluation Framework](http://lcl.uniroma1.it/wsdeval/)。英语入口本次未能成功加载，未验证其下载状态；上游非英语材料不能直接替代项目英语输入。

1. 打开 [上游 README](https://github.com/SapienzaNLP/mwsd-datasets#readme)，通过其 Multilingual datasets 链接获取所需压缩包，记录下载日期、文件哈希及选择的子集。不要仅克隆仓库就假定取得数据包。
2. 核对论文实际使用的评测年份、语言、`all`/`wn` 子集及词义映射；论文给出了上游地址，但没有唯一指定这些选择。上游也包含多个评测集，不能从本项目 `sem13_*` 命名推断所有语言文件都未经合并或筛选。
3. 解压后按上游目录说明找到 `.data.xml` 和 `.gold.key.txt` 等材料，按实例 ID 关联句子与标签。向本项目 CSV 转换时，需保留目标词位置、多词表达和多个正确标签，并记录重建文本的分词/标点处理。
4. 补充可核查的筛选和难度标注规则、独立示例库来源及评估划分，再转换为下述输入格式。现存论文与脚本未包含一份完整的原始 XML 到项目 CSV 的转换程序，当前不提供声称等价于原处理流程的转换脚本。
5. 从独立授权词义资源建立候选缓存，并检查其标识符版本与数据相容。上游提供 inventory 构建指引；其 `withgold` 文件不能未经审查直接当作本公开版的独立候选词典，须确认候选构建不依赖评估正确标签。

上游涉及 BabelNet 4.0 的词义映射；这不足以单独证明本项目缓存也使用完全相同的构建版本。上游许可段落含非商业与共享条款的表述，且名称与括号缩写不一致，应以实际下载包及权利人适用条款核实。本仓库 MIT 不覆盖这些数据或词义资源，因此这里仅提供来源链接和准备指引，不重新分发材料。

## 补齐材料的边界

公开上游可用于重新获取真实数据材料并组织新实验；精确恢复项目当时的 CSV 仍需确认版本、选择规则、转换、难度划分及示例库设置。`artificial` 和 `problem` 的具体句子和标签不能由论文中的构造概述唯一还原。如重新生成，应明确记录为新构造的数据，不冒充历史原始输入。

## 路径

对每个所选语言 `LANG`，文件布局为：

```text
data/                         # 仅评估集
  LANG/sem13_LANG.csv          # real
  artificial_LANG.csv         # artificial
  problem_LANG.csv            # problem
support_data/                 # 独立示例库，采用同样的文件名和子目录
  LANG/sem13_LANG.csv
  artificial_LANG.csv
  problem_LANG.csv
resources/
  babelnet_inventory_cache_healed.json
```

`LANG` 取 `en`、`fr`、`de`、`es`、`it`。只准备本次所选的数据类型及语言；每种数据类型的示例库额外需要英语文件。`--data-dir`、`--support-dir`、`--inventory` 可覆盖默认路径。评估目录与示例库目录不得相同。

## CSV 字段

| 字段 | 约束及用途 |
| --- | --- |
| `sentence` | 非空句子，恰含一个非空 `<WSD>目标词</WSD>` 标记对 |
| `senseid` | 完整 BabelNet 风格 ID（`bn:` 后跟数字和小写词性字母），或末尾为 `::` 的 WordNet 风格键（实现支持的子集）；多个正确 ID 使用逗号或空白分隔 |
| `complexity` | 评估集必需；取 `simple`、`medium`、`complex`；用于数据分层，示例库可不提供 |
| `frequency_weight` | 可选；有限非负数；空缺按 1.0 处理，仅影响语义示例排序 |

编码使用 UTF-8，可含 BOM。`complexity` 是输入分层标签；自适应策略另外根据原始标记句子的空格分词数和标点数计算复杂度，二者不能混同。脚本不会从缺失列推断层级，防止同一批样本重复计入三个层级。

## 候选词义缓存

【该配置文件需要使用者自行根据数据集/模型凭证补充】：`resources/babelnet_inventory_cache_healed.json`。

顶层为 JSON 对象，键为 `语言代码:小写目标词`；为兼容现存格式，也支持仅小写目标词作为回退键。值为非空列表，每项包含字符串 `id`（单个完整词义 ID）和非空字符串 `gloss`。英语键还用于建立词义到英语 lemma 的桥接索引。

候选集合必须来自独立词典或预先确定的资源，不得用评估集正确标签建立、补齐或缩减候选集合。检查标签覆盖仅用于发现错误输入，不改变词典。缓存的资源版本、构建方法和许可均需使用者记录。

## 划分与审计

示例库可使用经授权的训练/开发标注，评估样本只用于评分。程序阻止去除标记、大小写和连续空白差异后的完全相同句子跨集合出现；无法自动检测翻译对齐、近重复、同一文档、实体或构建过程中的泄漏。使用者应按文档或平行语料来源建立隔离划分，并记录授权来源、处理流程、样本筛选、层级划分、文件版本和 SHA-256。

论文提供了真实数据上游来源；公开版尚需核实项目输入与该上游的具体对应关系。使用未经核对的处理子集或自行重建的难度标签时，应说明新处理协议，不应声称与论文原始输入逐条一致。
